Privacy Policy

FishingBuddy Privacy Policy

Draft date: July 2, 2026

This privacy policy applies to the current iOS app published as FishingBuddy or Balikci Market. The final public app name should match App Store Connect before this page is published.

Overview

The app is designed as a local-first fishing assistant. It helps users plan fishing trips, save personal fishing spots, review weather-aware fishing guidance, identify fish from selected photos, read a fish guide, and keep catch records on device.

Data Collection

The current MVP does not include user accounts, a backend database, analytics SDKs, advertising SDKs, third-party tracking, fish-photo uploads, CloudKit or iCloud sync, or a remote Fishial API.

User-created fishing spots, catch records, preferences, and related fishing notes are stored locally on the user's device in the current build.

Photos

The app can use the system photo picker when a user selects an image for fish identification or local catch records. In the current build, selected fish photos are processed on device with a bundled Core ML model. The app does not upload selected fish photos to a server.

Location

The app can request when-in-use location permission for the Spots map. Location is used to center the map near the user. Saved fishing spot coordinates are stored locally when the user creates or edits spots.

Weather And Maps

The app uses Apple WeatherKit for weather-aware fishing guidance. WeatherKit requests weather for coordinates through Apple's weather services.

The app uses Apple MapKit for maps. MapKit may load map tiles and related platform map services from Apple.

Tracking And Advertising

The current build does not track users across apps or websites. It does not include advertising networks or analytics SDKs.

Local Data Removal

Because the current MVP stores user-created data locally, deleting the app from the device removes the app's local MVP data from that device.

Children's Privacy

The current MVP is a general fishing utility and does not include account creation, messaging, unrestricted web access, or user-generated public content.

Changes
